# Luminiferous

Physics and earth science, explained interactively.

- `index.html` is the home page (two columns: Popular science and Education); `popular-science.html` and `education.html` list each section
- `assets/content.js` is the list of everything shown as a tile (edit this to add content; tiles sort newest first)
- `explainers/` holds the interactive lesson pages; `articles/` holds popular science articles
- `assets/style.css` is the shared look; `assets/nav.js` is the tab bar; `assets/lists.js` draws the tiles
