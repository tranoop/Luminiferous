# Luminiferous

Physics and earth science, explained interactively.

- `index.html` is the home page; `popular-science.html` and `education.html` list each section
- `explainers/` holds the interactive lesson pages (listed on the Education tab)
- `articles/` holds popular science articles (start from `article-template.html`)
- `assets/style.css` is the shared look; `assets/nav.js` is the tab bar (edit it to add or rename a tab)
