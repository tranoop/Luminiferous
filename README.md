# Luminiferous

Exploring science and transmitting knowledge.

- `index.html` is the home page (two columns: Popular Science and Education); `popular-science.html`, `education.html` and `about.html` are the other tabs
- `assets/content.js` is the list of everything shown as a tile (edit this to add content; tiles sort newest first, each can have a thumbnail)
- `articles/` holds popular science articles (copy `article-template.html` to start one); `explainers/` holds the interactive lessons
- `assets/thumbs/` holds tile thumbnails (16:9, 640 x 360); `assets/share/` holds link-preview pictures (1200 x 630)
- `assets/style.css` is the shared look; `assets/nav.js` is the tab bar; `assets/lists.js` draws the tiles
